# AXIDIA

スマホ向け（横画面）のWebリズムゲーム。上から降ってくるノーツを、判定ラインに重なった瞬間に処理します。

- **横画面専用**: 縦向きでは「横向きにしてください」と表示します（Android Chrome では全画面＋向きロックも試みます）
- **上下2本の判定ライン**: 下ラインへは上端からノーツが降ってきて、上ラインへは下端からノーツが上がってきます（上下反転）。画面の上半分のタッチは上ライン、下半分のタッチは下ラインの判定になります
- **フリック（ひし形）**: 画面中央にひし形がフェードで現れ、画面外からひし形のガイドがズームインして重なった瞬間が判定タイミングです
- **スライド**: 9つの基準点（上ライン・中段・下ラインの左・中央・右。左右の点の間隔＝上下ラインの間隔で正方形を作る）を、好きなだけ中継しながら直線または円弧で結ぶノーツ。円弧は半径＝TL–ML間の距離で、斜め隣の点同士（90°の円弧）か2マス離れた点同士（半円）をつなぎ、進行方向の左右どちらに膨らむかを区間ごとに選べる。開始2拍前に全体像がフェードで現れ、同時に「お手本」の光点が最初の2拍分をスライドの速度でなぞります（2拍より短いスライドは全体をなぞり終えたところで消えます）。スライド本番中も、お手本の光点が始点から終点まで全体をなぞります
- **同時押しガイド**: 同じタイミングのノーツ（上下ラインをまたぐものも含む）は淡い水色に光ります
- **判定はエフェクトで表示**: PERFECT＝黄色の大きなバースト＋光の柱＋破片 / GREAT＝水色の小さめのバースト / MISS＝赤
- **フリーレーン**: 固定レーンはありません。ノーツは横方向のどこにでも降ってきて、その位置で処理します
- **音楽と同期**: 譜面と同じBPM・長さの曲をブラウザ内で合成して再生（音声ファイルなし）。ゲームの時計は「実際に聞こえている曲の位置」に追従します
- **オフセット調整**: 端末ごとの音ズレを ±5ms 単位で調整。クリック音に合わせてタップするだけの自動測定もあり
- ビルド不要・依存なしの素の HTML / Canvas / ES Modules

## 遊び方

| ノーツ | 見た目 | 操作 |
| --- | --- | --- |
| TAP | 白いバー | 線に重なる瞬間にタップ |
| HOLD | 白いバー＋帯 | 頭をタップして、帯の終わりまで指を離さない |
| DRAG | 黄色の細いバー | 線に重なる瞬間にそこに指があればOK（タップ不要・なぞってよい） |
| FLICK | 中央のひし形 | ガイドが重なる瞬間に、ひし形の近くで指をどの方向にでも動かす（タップ判定なし） |
| SLIDE | 紫の線（矢印つき） | 始点と終点にタイミングどおり触れ、その間を矢印の向きになぞる（途中のペースは自由・タップ判定なし） |

- HOLD は「頭」と「終点」で2回判定されます。頭はタップと同じ判定、終点は最後まで押し続ければ PERFECT、途中で離すと MISS（終点の150ms前以降は離してもOK）
- DRAG・FLICK・SLIDE は PERFECT か MISS のみ
- SLIDE は始点と終点の2点で判定（各1点）。当たり判定は各点から半径100px（短いスライドではスライド長の60%まで縮む）
  - 始点: ガイドが出た瞬間（2拍前）から終点の受付が終わるまでの間に、始点の近くに指があれば PERFECT
  - 中間点: スライド上に見えない中間点（各区間を約70px間隔で分割、中継点も含む。1区間だけなら最低2個）があり、始点を取った指が近く（50px）を順番どおりに、その地点でのスライドの進行方向に沿って動きながら通過する必要がある（これが方向の判定になる）。1個飛ばしまでは許容（最初の1個は除く）、2個連続で飛ばすと先に進めず終点は MISS。指がスライドからずれても、戻ってくればそのまま続きをなぞれる。指を離しても、中断した付近（最後に通過した中間点〜2つ先の中間点の区間、50px以内）に別の指で触れれば続きからなぞれる
  - 終点: 始点を取った指が中間点を通過して終点の近くにあること。その状態になった瞬間が ±250ms 以内に一度でもあれば PERFECT、±400ms 以内なら GREAT、なければ MISS（早めに着いて待っていても、一瞬範囲から出ても PERFECT）

| 判定 | タイミング幅 |
| --- | --- |
| PERFECT | ±45ms |
| GREAT | ±135ms |
| MISS | それ以外・見逃し |

ノーツの左右（ノーツ幅 + 少しの余裕）以内なら当たり判定になります。
スコアは 1,000,000 点満点（PERFECT 100% / GREAT 70%）。

## 画面の流れ

タイトル（TAP TO START）→ 選曲（左に曲のリスト、右に曲情報・難易度 EASY / NORMAL / HARD・ノーツ数・ベスト・START。右上 SETTINGS で SPEED / TAP SOUND / OFFSET / 遊び方）→ プレイ → リザルト → 選曲。

選曲画面は START でひし形に縮んで消え、その下ですでにプレイが始まっています。リザルトやポーズから戻るときは、ひし形が中央から広がって選曲画面が現れます。

## 曲の追加

曲は `web/src/songs.js` の `SONGS` に並べます。テスト楽曲は譜面も曲もコードで生成していますが、実際の曲はファイルから読み込めます。

```js
{
  id: 'my-song',
  title: '曲名',
  artist: 'アーティスト',
  bpm: 128,
  audio: 'songs/my-song/audio.mp3',            // web/ からの相対パス
  charts: {
    EASY: 'songs/my-song/easy.json',
    NORMAL: 'songs/my-song/normal.json',
    HARD: 'songs/my-song/hard.json',
  },
}
```

譜面 JSON:

```json
{
  "bpm": 128,
  "offset": 0,
  "notes": [
    { "type": "tap", "side": "bottom", "beat": 4, "x": 0.5 },
    { "type": "hold", "side": "top", "beat": 6, "endBeat": 8, "x": 0.2 },
    { "type": "drag", "side": "bottom", "beat": 9, "x": 0.8 },
    { "type": "flick", "beat": 10 },
    { "type": "slide", "beat": 12, "endBeat": 14, "path": ["TL", "MC", "BR"], "bends": [null, "L"] }
  ]
}
```

- 時刻は `beat`（`offset` ms を 0 拍目とした拍数）か `time`（音源の先頭からの ms）で書けます。ホールド・スライドの終点は `endBeat` か `end`
- `side` は `top` / `bottom`（フリックとスライドは不要）、`x` は 0〜1 の横位置
- 音源の 0ms が譜面の 0ms です

`?debug` を付けて開くと、選曲画面にスライド確認用の曲（全スライド形状）が出ます。

## 譜面エディタ

`editor.html`（ゲームの SETTINGS からもリンク）で譜面を作れます。PC（マウス＋キーボード）向けです。

- **音源**: 音源ファイルを読み込む（ボタン or タイムラインにドロップ）。読み込まなければテスト楽曲の音（BPM と長さに合わせて生成）で作業できます。音量スライダーは再生とテストプレイの両方に効きます
- **同期**: BPM と OFFSET（0拍目が音源の何ms目か）を、左端の波形と小節線が重なるように合わせます。OFFSET は ±1 / ±10ms ボタンで微調整。再生中はメトロノームとヒット音で確認できます（0.75x / 0.5x のスロー再生も可）
- **タイムライン**: 時間は下から上へ流れ、赤い線が現在位置。列は 小節番号＋波形 / TOP LINE / BOTTOM LINE / FLICK / SLIDE。ホイールでスクロール、Ctrl+ホイールでズーム、左端の列はドラッグでもスクロール・クリックでカーソル移動
- **スライドのガイド**: SLIDE 列の点線の範囲（開始の2拍前から）が、ゲームでスライドのガイドが表示されている区間です
- **全体バー**: タイムライン右端の細い列に曲全体（波形・全ノーツ・表示中の範囲・現在位置）。クリック / ドラッグでその位置へ一気に移動（再生中なら続きから再生）
- **配置**（スナップ 1/1〜1/16、横位置は 0.05 刻みにそろえる設定あり）
  - TAP: クリック / HOLD: クリックして上にドラッグで長さ / DRAG: ドラッグで連続配置（横移動にも追従）/ FLICK: FLICK 列をクリック / SLIDE: SLIDE 列をクリック＆ドラッグで長さ
  - ノーツはドラッグで移動（TOP / BOTTOM 間の移動も可）、上端ドラッグで長さ変更、右クリック or Delete で削除
- **複数選択・コピー＆ペースト・左右反転**: 選択ツールで空いている所をドラッグして範囲選択（Shift+ドラッグはどのツールでも）、Shift+クリックで追加・解除、Ctrl+A で全選択。選択中のノーツはまとめてドラッグで移動・Delete で削除。Ctrl+C / Ctrl+X でコピー / 切り取り、Ctrl+V で赤い線の位置に貼り付け（別タブや再読み込み後でも可）。M で左右反転（ライン上のノーツは横位置、スライドは経路と円弧の向き。フリックは中央のまま）
- **選択中のノーツ**: 拍・長さ・ライン・横位置を数値で編集。スライドは 3×3 の点を順にクリックして経路を作り、区間ごとに 直線 / `(` 左に膨らむ / `)` 右に膨らむ を選択（円弧は斜め隣か2マス離れた点同士のみ）
- **テストプレイ**: カーソル位置から（Shift で最初から）実際のゲームで遊べます。右パネルの「テストプレイ」で SPEED・OFFSET（端末の音ズレ補正。タイミング欄の OFFSET＝曲の0拍目の位置とは別）・タップ音（SE）のオンオフ・オート（全ノーツを自動で PERFECT）を設定（初期値はゲームの設定）。Esc で戻る
- **全画面**: ヘッダーの「全画面」（F キー）でアドレスバーなしの全画面に。ブラウザの「アプリとしてインストール」をすると、エディタ単体のアプリとして全画面で開けます
- **保存**: 「保存」で譜面 JSON をダウンロード（拍で記録）。「開く」かドロップで読み込み。作業中の譜面はブラウザに自動保存されます（音源は保存されないので開き直したら再度読み込み）
- **ショートカット**: Space 再生/停止、V/1〜5 ツール、Ctrl+A / C / X / V 全選択・コピー・切り取り・貼り付け、M 左右反転、F 全画面、↑↓ スナップ単位で移動（Shift で1小節）、Home 先頭、+/− ズーム、T テストプレイ、Ctrl+Z / Ctrl+Shift+Z 元に戻す/やり直す、Ctrl+S 保存

## 音楽とオフセット

- 曲は `web/src/music.js` で合成しています（1小節目はカウントのクリック、その後はキック＋クリック・スネア・ハイハット・ベース・コードの Am–F–C–G ループ、最後の拍でクラッシュ）。違う部分（カウント・4小節ループ・エンディング）だけを OfflineAudioContext でレンダリングして並べるので、生成は一瞬です
- 曲の再生位置（AudioContext の時計）と画面の時計（performance.now）の対応は `getOutputTimestamp()`（なければ `outputLatency`）で取り、出力遅延も含めて「聞こえている瞬間」に合わせています。プレイ中も毎フレーム少しずつ追従します
- **OFFSET**: 正の値ほど、ノーツと判定が曲に対して遅れます（音が遅れて聞こえる端末・Bluetoothイヤホンなどで＋にする）。タイトル画面の「測定する」で、クリック音に合わせて6回以上タップすると、タップの遅れの中央値が測定値になり、APPLY で反映されます
- iPhone はマナーモード（消音スイッチ）だと Web Audio の音が鳴りません

## スマホでテストする

### A. GitHub Pages（どこからでも）

`main` または `claude/**` ブランチに push すると `.github/workflows/pages.yml` が自動デプロイします。

初回のみ設定が必要です:

1. GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. **Settings → Environments → github-pages → Deployment branches** で、デプロイしたいブランチ（例: `claude/*`）を許可する（デフォルトブランチ以外から出す場合）
3. **Actions** タブから「Deploy to GitHub Pages」を再実行（または再 push）

公開URL: `https://<user>.github.io/axidia/`
タイトル画面下部の `build xxxxxxx` で、どのコミットが表示されているか確認できます。

> Pages はキャッシュされるため、更新直後は数分古い版が出ることがあります。

### B. ローカルネットワーク（PCとスマホが同じWi-Fi）

```sh
npm run dev        # または: node scripts/serve.mjs [port]
```

表示された `network: http://192.168.x.x:5173/` をスマホのブラウザで開きます。

### ホーム画面に追加

iOS Safari の「共有 → ホーム画面に追加」で、アドレスバーなしの全画面で遊べます。

### スライド確認（?debug）

`?debug` で選曲画面に出る「スライド確認」はスライドだけの確認用譜面です。直線・中段経由・V字・Z字・ループ・ひし形・蛇行と、円弧（90°・半円・円・S字・直線との組み合わせ）の計31種類の形を、いろいろな長さで1本ずつ流します。`chart.js` の `SLIDE_TESTS` で編集でき、`>` が直線、`)` が進行方向の右に膨らむ円弧、`(` が左に膨らむ円弧です（例: `ML)MR)ML` で円）。スライド同士は3拍空けてあり、各スライドのガイドは前のスライドが終わった1拍後に出ます。

### 譜面フォーマット

```js
{ bpm, beatMs, duration, notes: [{ type: 'tap' | 'drag' | 'hold' | 'flick' | 'slide', side: 'top' | 'bottom' | 'center' | 'free', time: ms, x: 0..1, end?: ms, path?: string[], bends?: ('L' | 'R' | null)[] }] }
```

`x` はプレイフィールド幅に対するノーツ中心の位置、`end` はホールド／スライドの終了時刻、`path` はスライドが通る基準点の列（`TL` `TC` `TR` `ML` `MC` `MR` `BL` `BC` `BR`、2個以上）、`bends` は区間ごとの形（`null` 直線、`'L'` / `'R'` 進行方向の左 / 右に膨らむ円弧）です。現在は難易度ごとに固定シードで生成しています。

### デバッグ

`?debug` を付けて開くと `window.__game` からゲーム状態を参照できます。
